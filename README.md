# SQL Insurance Analysis

## Summary

SQL analysis of an insurance customer table. The queries profile customers and premiums, then compare the positive response rate across customer groups.

## Questions

- How many customers are there, and what is their age profile?
- How does the annual premium change with vehicle age?
- Which regions have the most customers?
- What share of customers responded positively?
- How does the response rate differ by vehicle damage, vehicle age, previous insurance and age group?

## Tools

- MySQL

## Files

- `insurance_analysis.sql`: all queries, with a short comment above each one.

The query file expects a table named `insurance_data`. The dataset is not included in this repository.
